## 2. P0-1：单元格编辑与批量提交

### 2.1 背景与问题

Navicat 的数据编辑器允许用户直接在网格中编辑数据，修改后批量提交。这是数据库管理工具的核心功能。

### 2.2 功能需求

#### 2.2.1 编辑模式

| 模式 | 说明 |
|------|------|
| 只读模式 | 默认，单元格不可编辑 |
| 可编辑模式 | 双击进入编辑，需手动切换 |

工具栏新增"编辑模式"切换按钮，点击切换只读/可编辑。

#### 2.2.2 单元格编辑交互

| 操作 | 行为 |
|------|------|
| 双击单元格 | 进入编辑模式，光标定位到文本末尾 |
| 回车 | 提交编辑，移到下一行同列 |
| Tab | 提交编辑，移到同行下一列 |
| Esc | 取消编辑，恢复原值 |
| 点击其他单元格 | 提交当前编辑 |

#### 2.2.3 修改标记

| 标记 | 说明 |
|------|------|
| 行前 `*` | 已修改的行前显示星号标记 |
| 单元格背景色 | 已修改的单元格背景色变为浅黄色 `#FFF9C4` |
| 新行背景色 | 新插入的行背景色变为浅绿色 `#E8F5E9` |
| 待删除行背景色 | 待删除的行背景色变为浅红色 `#FFEBEE`，文字加删除线 |

#### 2.2.4 行操作

| 操作 | 按钮 | 行为 |
|------|------|------|
| 添加行 | 工具栏 `＋` 按钮 | 在表格底部添加空行（INSERT） |
| 删除行 | 工具栏 `🗑` 按钮 | 标记当前选中行为待删除（DELETE） |
| 提交更改 | 工具栏 `✅` 按钮 | 批量提交所有待提交变更 |
| 回滚更改 | 工具栏 `↩` 按钮 | 撤销所有未提交的变更 |
| 开始事务 | 工具栏 `🔒` 按钮 | 显式开启事务 |
| 保存点 | 工具栏 `💾` 按钮 | 创建保存点 |
| 回滚到保存点 | 工具栏 `↪️` 按钮 | 回滚到指定保存点 |

#### 2.2.4a 事务控制增强

提供更细粒度的事务控制能力：

| 功能 | 说明 |
|------|------|
| 自动/手动模式切换 | 配置项控制是否自动提交 |
| 显式事务控制 | 手动开启、提交、回滚事务 |
| 保存点支持 | 创建和回滚到保存点 |
| 事务状态显示 | 状态栏显示当前事务状态和执行时间 |
| 长事务警告 | 事务超过一定时间时显示警告 |

**事务工作流**：
1. 用户点击"开始事务"按钮
2. 状态栏显示：🔒 事务进行中 (00:01:23)
3. 进行数据编辑操作
4. 可选择创建保存点："编辑前"
5. 继续编辑，如出错可回滚到"编辑前"
6. 点击"提交"或"回滚"结束事务

新增配置项：
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sql-all-in-one.dataEditor.autoCommit` | `boolean` | `true` | 自动提交模式 |
| `sql-all-in-one.dataEditor.longTransactionWarning` | `number` | `300` | 长事务警告阈值(秒) |
| `sql-all-in-one.dataEditor.showTransactionStatus` | `boolean` | `true` | 显示事务状态 |

#### 2.2.5 PendingChange 追踪

| 变更类型 | 触发方式 | 生成的 SQL |
|---------|---------|-----------|
| `update` | 修改单元格值 | `UPDATE table SET col=newVal WHERE pk=pkVal` |
| `insert` | 添加新行 | `INSERT INTO table (cols) VALUES (vals)` |
| `delete` | 删除行 | `DELETE FROM table WHERE pk=pkVal` |

**PendingChange 结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | `'update' \| 'insert' \| 'delete'` | 变更类型 |
| `table` | `string` | 表名 |
| `primaryKey` | `Record<string, any>` | 主键值（update/delete 使用） |
| `changes` | `Record<string, { old: any, new: any }>?` | 字段变更（update 使用） |

**并发控制（乐观锁）**：

为防止多用户同时编辑时的静默覆盖，提交时进行版本校验：

| 策略 | 实现方式 |
|------|---------|
| 原始值比对 | `PendingChange` 中保存 `originalRow: Record<string, any>`（编辑前的完整行数据） |
| 提交时校验 | 执行 UPDATE 前先 `SELECT` 当前行数据，与 `originalRow` 比对 |
| 冲突处理 | 不一致时弹出差异对比对话框，用户选择"强制覆盖"或"放弃修改" |
| 时间戳策略（备选） | 若表有 `updated_at` 列，提交时增加 `WHERE updated_at = originalTimestamp` 条件 |

> **第一版范围**：乐观锁作为可选功能，受配置项 `sql-all-in-one.dataEditor.optimisticLocking` 控制，默认为 `false`（关闭）。后续迭代默认开启。

#### 2.2.6 批量提交流程

```
1. 用户点击"提交更改"
2. 收集所有 pendingChanges
3. 弹出确认对话框，显示即将执行的 SQL
4. 用户确认后：
   a. 遍历 pendingChanges，按类型排序（DELETE → UPDATE → INSERT）
   b. 若适配器支持事务（`supportsTransaction: true`），在事务中执行所有 SQL
   c. 全部成功 → 提交事务，清空 pendingChanges，刷新数据
   d. 部分失败 → 回滚事务，显示错误详情，保留 pendingChanges
   e. 若不支持事务，逐条执行（已执行的成功 SQL 不回滚）
5. 用户取消 → 不执行
```

> **缓存刷新**：批量提交成功后，若涉及 DDL 变更（如 ALTER TABLE），需调用 `SchemaCache.invalidate()` 刷新对应表的缓存（PRD-013），确保补全信息与数据库一致。

#### 2.2.7 确认对话框

```
📝 提交更改确认

即将执行以下 SQL:
  UPDATE users SET name='Bob_' WHERE id=2;

影响: 1 行修改
是否继续?

[执行] [取消]
```

#### 2.2.8 底部状态栏

```
待提交: 1 修改, 0 新增, 0 删除    [✅ 提交] [↩ 回滚]
```

**批量操作快捷键**（在可编辑模式下）：
| 快捷键 | 操作 |
|--------|------|
| `Ctrl+Enter` | 提交当前单元格编辑 |
| `Ctrl+S` | 提交所有待提交更改 |
| `Ctrl+Z` | 回滚最后一次单元格修改 |
| `Ctrl+Shift+Z` | 回滚所有未提交更改 |

#### 2.2.8a 数据校验规则

在编辑和提交前进行数据完整性校验：

| 校验类型 | 说明 |
|---------|------|
| 必填校验 | NOT NULL 字段不能为空 |
| 类型校验 | 确保输入值匹配列数据类型 |
| 长度校验 | VARCHAR/CHAR 列检查长度限制 |
| 范围校验 | 数值/日期列检查有效范围 |
| 枚举校验 | ENUM/SET 列检查有效值 |
| 外键校验 | 外键列值在引用表中存在 |
| 唯一校验 | UNIQUE 约束列检查重复 |
| 正则校验 | （可选）用户自定义正则表达式校验 |

**校验时机**：
1. 实时校验：编辑单元格时即时反馈
2. 提交前校验：批量提交前完整检查
3. 错误提示：在单元格旁显示错误图标和提示

新增配置项：
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sql-all-in-one.dataEditor.enableValidation` | `boolean` | `true` | 启用数据校验 |
| `sql-all-in-one.dataEditor.validateOnEdit` | `boolean` | `true` | 编辑时实时校验 |
| `sql-all-in-one.dataEditor.validateForeignKeys` | `boolean` | `false` | 外键校验（性能影响） |

#### 2.2.8b 批量编辑模式

支持Excel风格的快速批量编辑：

| 功能 | 说明 |
|------|------|
| 拖拽填充 | 选中单元格右下角拖拽填充序列或复制 |
| 批量替换 | 选中区域后批量替换值 |
| 公式计算 | 简单公式支持（求和、平均等） |
| 剪贴板粘贴 | 从Excel/CSV粘贴多行多列数据 |
| 智能填充 | 根据上下文自动推断填充内容 |

**批量编辑操作**：
1. 选中单元格区域
2. 右键菜单选择"批量编辑"
3. 选择操作（填充、替换、清除等）
4. 应用到选中区域

#### 2.2.9 新行占位

表格底部始终显示一行空行（背景浅灰），点击后变为新行编辑状态。

## 3. P0-2：表单视图、外键下拉与 ENUM 选择器

### 3.1 背景与问题

Navicat 提供表单视图逐条浏览记录，外键列的下拉选择器简化 FK 值选择，ENUM 列的下拉选择器避免输入错误。

### 3.2 功能需求

#### 3.2.1 表单视图

**布局**：

```
┌──────────────────────────────────────────────────────────┐
│ [◀ 上一条] [1/1234] [下一条 ▶]  [网格视图] [表单视图]    │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  id:         1                                           │
│  name:       Alice                                       │
│  email:      a@b.com                                     │
│  status:     [active ▼]          ← ENUM 下拉选择器       │
│  dept_id:    [3 ▼]               ← 外键下拉选择器        │
│  avatar:     [查看图片]           ← BLOB 预览按钮        │
│  bio:        Lorem ipsum...      ← TEXT 展开编辑器       │
│  created_at: 2024-01-01 00:00                           │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**表单视图交互**：

| 操作 | 行为 |
|------|------|
| 上一条 | 显示上一条记录 |
| 下一条 | 显示下一条记录 |
| 网格视图 | 切换回网格视图 |
| 字段编辑 | 可编辑模式下，点击字段值进入编辑 |

**字段显示规则**：

| 数据类型 | 显示方式 |
|---------|---------|
| 数值/字符串 | 文本输入框 |
| ENUM/SET | 下拉选择器 |
| 外键 | 下拉选择器（显示引用表的值） |
| TEXT/LONGTEXT | 文本区域 + 展开按钮 |
| BLOB | 预览按钮（文本/十六进制/图片） |
| DATETIME | 日期时间输入框 |
| NULL | 灰色斜体 "NULL"，点击可编辑 |

#### 3.2.2 外键下拉选择器

**触发条件**：列的 `referencedTable` 属性非空。

**行为**：
1. 编辑外键列时，发送 `requestForeignKeyOptions` 消息
2. 扩展端查询：`SELECT {pk}, {display_col} FROM {referenced_table} LIMIT 100`
3. `display_col` 优先选择有 COMMENT 的 VARCHAR 列，否则选择第一个非主键列
4. 返回 `ForeignKeyOption[]` 给 Webview
5. Webview 渲染为下拉选择器

**ForeignKeyOption 结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | `any` | 外键值（主键值） |
| `displayText` | `string` | 显示文本（如 "3 - 技术部"） |

#### 3.2.3 ENUM/SET 选择器

**触发条件**：列的 `isEnum` 为 `true` 或 `enumValues` 非空。

**行为**：
1. 编辑 ENUM 列时，直接从 `ColumnMeta.enumValues` 获取可选值
2. 渲染为下拉选择器
3. SET 类型支持多选

#### 3.2.4 BLOB 预览

**触发条件**：列类型为 `BLOB`、`LONGBLOB`、`TINYBLOB`、`MEDIUMBLOB`。

**行为**：
1. BLOB 列显示 `[查看]` 按钮
2. 点击按钮弹出预览窗口
3. 三种预览模式：
   - 文本模式：尝试 UTF-8 解码
   - 十六进制模式：显示十六进制转储
   - 图片模式：如果数据是图片格式（JPEG/PNG/GIF），显示图片

**BLOB 预览限制**：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sql-all-in-one.dataEditor.maxBlobPreviewSize` | `number` | `5242880` (5MB) | BLOB 预览最大字节数 |
| `sql-all-in-one.dataEditor.blobTextPreviewSize` | `number` | `1048576` (1MB) | BLOB 文本预览最大字节数 |

- BLOB 大小超过 `maxBlobPreviewSize` 时，不自动加载内容，显示"[下载文件 (X.XX MB)]"按钮
- BLOB 大小在 `blobTextPreviewSize` 以内时尝试文本预览
- 图片检测仅在前 256 字节内进行（检查 magic bytes）
- 点击"下载"按钮通过 `vscode.window.showSaveDialog` 将 BLOB 内容保存到本地文件

#### 3.2.5 Webview 通信协议扩展

新增消息：

**扩展 → Webview**：

| 消息类型 | 数据 | 说明 |
|---------|------|------|
| `foreignKeyOptions` | `{ column, options: ForeignKeyOption[] }` | 外键选项列表 |
| `commitResult` | `{ success, errors? }` | 提交结果 |

**Webview → 扩展**：

| 消息类型 | 数据 | 说明 |
|---------|------|------|
| `commitChanges` | `PendingChange[]` | 提交变更 |
| `requestForeignKeyOptions` | `{ column }` | 请求外键选项 |
| `switchView` | `{ view: 'grid' \| 'form' }` | 切换视图 |

| `sql-all-in-one.dataEditor.blobTextPreviewSize` | `number` | `1048576` | BLOB 文本预览最大字节数 |
| `sql-all-in-one.dataEditor.longTransactionWarning` | `number` | `300` | 长事务警告阈值(秒) |
| `sql-all-in-one.dataEditor.showTransactionStatus` | `boolean` | `true` | 显示事务状态 |
| `sql-all-in-one.dataEditor.enableValidation` | `boolean` | `true` | 启用数据校验 |
