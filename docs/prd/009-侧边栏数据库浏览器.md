## 1. 功能概览

实现侧边栏数据库浏览器，对标 Navicat 的对象浏览器，按"连接 → 数据库 → 对象类型 → 对象"层级展示，支持虚拟组、收藏夹、对象筛选。

| 编号 | 功能 | 一句话描述 | 用户感知强度 |
|------|------|-----------|-------------|
| P0-1 | 树节点定义与 TreeProvider | 懒加载的树形视图，浏览数据库对象 | ★★★★★ |
| P0-2 | 右键菜单与快捷操作 | Navicat 风格的右键操作和双击快捷操作 | ★★★★☆ |
| P0-3 | 收藏夹与对象搜索 | 收藏常用对象，全局搜索数据库对象 | ★★★☆☆ |

## 2. P0-1：树节点定义与 TreeProvider

### 2.1 背景与问题

需要一个侧边栏树形视图来浏览数据库对象。Navicat 的对象浏览器是其核心交互入口，本功能对标实现。

### 2.2 功能需求

#### 2.2.1 树形视图结构

```
📦 SQL All in One
├── 🔍 搜索对象...                     ← 全局搜索框
├── ⭐ 收藏夹                          ← 收藏夹
│   ├── 📋 users
│   └── 📋 orders
├── 📁 开发环境 🟢                     ← 连接分组（带颜色标识）
│   ├── 🔌 开发库-MySQL 🟢 [已连接]    ← 连接节点（带颜色圆点）
│   │   ├── 📂 mydb                    ← 数据库节点
│   │   │   ├── 📋 表 (12)            ← 表分组（显示数量）
│   │   │   │   ├── 📋 users          ← 表节点
│   │   │   │   │   ├── 🔑 id INT PK AI
│   │   │   │   │   ├── 📧 email VARCHAR(255) UK
│   │   │   │   │   └── 📊 索引 (2)
│   │   │   │   │       ├── idx_email (UNIQUE)
│   │   │   │   │       └── idx_created_at
│   │   │   │   └── 📋 orders
│   │   │   ├── 👁 视图 (3)           ← 视图分组
│   │   │   ├── ⚡ 函数 (5)           ← 函数分组
│   │   │   ├── ⚙ 存储过程 (2)       ← 存储过程分组
│   │   │   └── 🔔 触发器 (1)         ← 触发器分组
│   │   └── 📂 information_schema
│   └── 🔌 测试库-MySQL ⚪ [未连接]
├── 📁 生产环境 🔴
│   └── 🔌 主库-MySQL ⚪ [未连接]
└── ＋ 添加新连接
```

**与 Navicat 的关键差异**：Navicat 是独立窗口应用，对象标签页（Tables/Views/Functions）作为平级标签。在 VSCode 侧边栏中，采用**分组折叠**方式，将对象类型作为数据库节点下的子分组，更适配窄面板。

#### 2.2.2 树节点类型

| 节点类型 | 图标 | 可折叠 | 上下文值 | 说明 |
|---------|------|--------|---------|------|
| `GroupNode` | 📁 | 是 | `group` | 连接分组 |
| `ConnectionNode` | 🔌 | 是 | `connectionConnected` / `connectionDisconnected` / `connectionError` | 数据库连接 |
| `DatabaseNode` | 📂 | 是 | `database` | 数据库 |
| `ObjectGroupNode` | 📋/👁/⚡/⚙/🔔 | 是 | `objectGroup` | 对象分组（表/视图/函数/存储过程/触发器） |
| `TableNode` | 📋 | 是 | `table` | 表 |
| `ViewNode` | 👁 | 否 | `view` | 视图 |
| `FunctionNode` | ⚡ | 否 | `function` | 函数 |
| `ProcedureNode` | ⚙ | 否 | `procedure` | 存储过程 |
| `TriggerNode` | 🔔 | 否 | `trigger` | 触发器 |
| `ColumnNode` | 🔹 | 否 | `column` | 列 |
| `IndexNode` | 📊 | 否 | `index` | 索引 |
| `FavoritesNode` | ⭐ | 是 | `favorites` | 收藏夹根节点 |

#### 2.2.3 列节点图标规则

| 列属性 | 图标 | 示例 |
|--------|------|------|
| 主键 | 🔑 | `🔑 id INT PK AI` |
| 唯一键 | 🛡 | `🛡 email VARCHAR(255) UK` |
| 外键 | 🔗 | `🔗 dept_id INT FK` |
| 普通列 | 🔹 | `🔹 name VARCHAR(255)` |

#### 2.2.4 连接节点状态显示

| 状态 | 图标 | 描述文本 | 颜色 |
|------|------|---------|------|
| 已连接 | 🟢 | 连接名 | 连接配置的 color |
| 未连接 | ⚪ | 连接名 | 默认 |
| 连接中 | 🔄 | 连接名 [连接中] | 默认 |
| 错误 | 🔴 | 连接名 [错误] | 红色 |

#### 2.2.5 懒加载策略

| 节点展开 | 加载方式 | 数据来源 |
|---------|---------|---------|
| 根节点 | 一次性加载 | ConnectionStore + 分组信息 |
| 连接节点 | 展开时加载 | `adapter.listDatabases()` |
| 数据库节点 | 展开时加载 | `adapter.listTables()` + `listViews()` + `listFunctions()` + `listProcedures()` + `listTriggers()` |
| 对象分组 | 展开时加载 | 从已加载的数据中过滤 |
| 表节点 | 展开时加载 | `adapter.describeTable()` |
| 收藏夹 | 一次性加载 | GlobalState |

#### 2.2.6 大数据库性能约束

当数据库包含大量对象（如 500+ 张表）时，需采取以下性能保护措施：

| 约束 | 默认值 | 说明 |
|------|--------|------|
| 单次加载表上限 | `500` | 超过上限时截断显示，底部显示"仅显示前 500 张表，使用搜索查找更多" |
| 对象分组默认折叠 | — | 表/视图/函数等分组节点默认折叠，点击展开时才加载对象列表 |
| 列信息懒加载 | — | 列节点仅在表节点展开时加载，不随对象列表一起加载 |
| 虚拟滚动 | — | 对于超过 100 个对象的列表，启用虚拟滚动，只渲染可视区域节点 |

新增配置项：
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sql-all-in-one.explorer.maxTableListSize` | `number` | `500` | 单次加载表的最大数量 |
| `sql-all-in-one.explorer.showSystemDatabases` | `boolean` | `false` | 是否显示系统数据库（information_schema/mysql/performance_schema/sys） |
| `sql-all-in-one.explorer.enableVirtualScroll` | `boolean` | `true` | 启用虚拟滚动 |
| `sql-all-in-one.explorer.virtualScrollThreshold` | `number` | `100` | 启用虚拟滚动的对象数量阈值 |

#### 2.2.7 最近访问（MRU）功能

在侧边栏顶部显示最近访问的数据库对象，方便快速切换常用对象：

| 功能 | 说明 |
|------|------|
| MRU 列表显示 | 在收藏夹上方显示"最近访问"分组 |
| 自动记录 | 打开表、查看视图、执行查询时自动记录 |
| 手动移除 | 右键可移除单个条目 |
| 清空历史 | 右键菜单提供"清空最近访问"选项 |
| 可配置数量 | 默认显示 10 个，可在设置中调整 |

新增配置项：
| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `sql-all-in-one.explorer.showRecentItems` | `boolean` | `true` | 显示最近访问列表 |
| `sql-all-in-one.explorer.maxRecentItems` | `number` | `10` | 最近访问列表最大数量 |

#### 2.2.8 TreeView 注册

在 `package.json` 中注册：

```json
"views": {
  "explorer": [
    {
      "id": "sql-all-in-one.databaseExplorer",
      "name": "SQL All in One",
      "icon": "$(database)"
    }
  ]
},
"viewsWelcome": [
  {
    "view": "sql-all-in-one.databaseExplorer",
    "contents": "No database connections.\n[Add Connection](command:sql-all-in-one.addConnection)"
  }
]
```

#### 2.2.9 DatabaseTreeProvider API

| 方法 | 说明 |
|------|------|
| `getChildren(element?)` | 获取子节点，根节点返回分组和连接 |
| `getTreeItem(element)` | 返回 TreeItem，设置图标、标签、上下文值 |
| `getParent(element)` | 返回父节点（用于 reveal） |
| `refresh(element?)` | 刷新指定节点或整棵树 |

#### 2.2.10 事件驱动刷新

监听 `ConnectionManager` 事件自动刷新：
- `onDidChangeConnections` → 刷新根节点
- `onDidChangeConnectionState` → 刷新对应连接节点
- 配置变更 → 刷新整棵树

#### 2.2.11 连接断开时的树行为

- 连接断开时，已展开的连接节点自动折叠
- 连接节点的子节点缓存清除，下次展开时重新加载
- 断开连接的节点显示为未连接状态（⚪）
- 如果断开的是活动连接，侧边栏标题栏显示"未连接"提示

## 3. P0-2：右键菜单与快捷操作

### 3.1 背景与问题

Navicat 的右键菜单是其核心交互方式之一，用户通过右键操作完成大部分数据库操作。

### 3.2 功能需求

#### 3.2.1 右键菜单定义

> **迭代依赖说明**：以下右键菜单中，部分功能依赖后续迭代实现。V2 阶段仅启用不依赖后续迭代的命令，其他命令使用 `when` 条件隐藏或灰显。具体依赖关系如下：
> - "打开表" / "新建查询" / "命令行界面" → 依赖 PRD-010（SQL 执行引擎）
> - "设计表" → 依赖 PRD-014（表设计器）
> - "转储 SQL 文件" / "运行 SQL 文件" → 依赖 PRD-015（高级功能）

| 节点类型 | 右键操作 |
|---------|---------|
| 分组节点 | 新建连接、重命名分组、删除分组、设置分组颜色 |
| 连接节点（已连接） | 断开、编辑连接、复制连接、删除连接、刷新全部、新建查询、命令行界面 |
| 连接节点（未连接） | 连接、编辑连接、复制连接、删除连接 |
| 数据库节点 | 设为默认数据库、新建查询、转储 SQL 文件、运行 SQL 文件 |
| 表分组节点 | 新建表、筛选表、批量操作 ▸ |
| 表节点 | 打开表、设计表、查看 DDL、生成 SQL ▸、转储数据、添加到收藏夹 |
| 视图节点 | 打开视图、查看定义 |
| 函数节点 | 查看定义 |
| 存储过程节点 | 查看定义 |
| 触发器节点 | 查看定义 |
| 列节点 | 复制列名、复制列定义 |

#### 3.2.1a 批量操作

支持多选对象进行批量操作，提升效率：

| 批量操作 | 说明 |
|---------|------|
| 批量导出 DDL | 导出多个表/视图的建表语句 |
| 批量导出数据 | 导出多个表的数据为 CSV/JSON/SQL |
| 批量删除 | 删除多个表/视图（二次确认） |
| 批量复制 | 复制多个表到同一数据库或其他连接 |
| 批量添加到收藏夹 | 将多个对象同时添加到收藏夹 |

**操作流程**：
1. 按住 `Cmd/Ctrl` 键点击多选对象
2. 右键菜单显示"批量操作"子菜单
3. 选择批量操作后弹出确认对话框
4. 显示操作影响范围（如"将删除 5 个表"）
5. 用户确认后执行操作
6. 显示操作结果（成功数量、失败数量、错误详情）

#### 3.2.2 表节点"生成 SQL"子菜单

| 选项 | 生成的 SQL |
|------|-----------|
| SELECT | `SELECT * FROM table_name WHERE 1=1;` |
| INSERT | `INSERT INTO table_name (col1, col2, ...) VALUES (val1, val2, ...);` |
| UPDATE | `UPDATE table_name SET col1 = val1 WHERE 1=1;` |
| DELETE | `DELETE FROM table_name WHERE 1=1;` |
| CREATE | `CREATE TABLE table_name (...);`（从 DDL 获取） |
| DROP | `DROP TABLE IF EXISTS table_name;` |

#### 3.2.3 快捷操作

| 操作 | 触发方式 | 行为 |
|------|---------|------|
| 双击表 | 双击表节点 | 自动生成 `SELECT * FROM table LIMIT 100` 并执行 |
| 双击视图 | 双击视图节点 | 同上 |
| 双击列 | 双击列节点 | 复制列名到剪贴板 |
| 拖拽表名 | 从树视图拖拽到编辑器 | 插入表名文本 |
| 右键数据库 → 新建查询 | 点击菜单项 | 新建 .sql 文件并自动添加 `USE database` |
| Ctrl+Q | 快捷键 | 新建查询（自动设置连接上下文） |

#### 3.2.4 "设为默认数据库"行为

- 更新连接配置中的 `database` 字段
- 后续该连接的查询默认使用此数据库
- 数据库节点标签加粗显示默认数据库

#### 3.2.5 "命令行界面"行为

- 在 VSCode 终端中打开 `mysql` CLI
- 自动填入连接参数：`mysql -h host -P port -u user -p database`
- 密码不自动填入，由用户手动输入

#### 3.2.6 "查看 DDL"行为

- 调用 `adapter.getTableDDL()` 获取 DDL
- 在新的编辑器标签页中展示 DDL 文本
- 语言模式设为 SQL，支持语法高亮

#### 3.2.7 package.json 菜单注册

```json
"menus": {
  "view/item/context": [
    { "command": "sql-all-in-one.connect", "when": "view == sql-all-in-one.databaseExplorer && viewItem == connectionDisconnected", "group": "1_connection@1" },
    { "command": "sql-all-in-one.disconnect", "when": "view == sql-all-in-one.databaseExplorer && viewItem == connectionConnected", "group": "1_connection@1" },
    { "command": "sql-all-in-one.editConnection", "when": "view == sql-all-in-one.databaseExplorer && viewItem =~ /connection/", "group": "2_manage@1" },
    { "command": "sql-all-in-one.removeConnection", "when": "view == sql-all-in-one.databaseExplorer && viewItem =~ /connection/", "group": "2_manage@2" },
    { "command": "sql-all-in-one.viewTableData", "when": "view == sql-all-in-one.databaseExplorer && viewItem == table", "group": "3_table@1" },
    { "command": "sql-all-in-one.viewTableDDL", "when": "view == sql-all-in-one.databaseExplorer && viewItem == table", "group": "3_table@2" },
    { "command": "sql-all-in-one.newQuery", "when": "view == sql-all-in-one.databaseExplorer && viewItem =~ /database|connectionConnected/", "group": "4_query@1" },
    { "command": "sql-all-in-one.refreshSchema", "when": "view == sql-all-in-one.databaseExplorer && viewItem =~ /database|objectGroup|connectionConnected/", "group": "5_refresh@1" }
  ]
}
```

## 4. P0-3：收藏夹与对象搜索

### 4.1 背景与问题

Navicat 提供收藏夹和数据库范围搜索功能，方便用户快速定位常用对象和搜索特定对象。

### 4.2 功能需求

#### 4.2.1 收藏夹

**数据存储**：VSCode GlobalState，Key: `sql-all-in-one.favorites`

**收藏夹条目结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `connectionId` | `string` | 所属连接 ID |
| `connectionName` | `string` | 连接名称 |
| `database` | `string` | 数据库名 |
| `objectType` | `ObjectType` | 对象类型 |
| `objectName` | `string` | 对象名称 |

**收藏夹行为**：
- 收藏夹节点始终显示在树顶部
- 右键表/视图 → "添加到收藏夹"
- 右键收藏夹条目 → "从收藏夹移除"
- 点击收藏夹条目 → 定位到树中对应节点（如果连接已建立）
- 收藏夹条目显示格式：`连接名/数据库名/对象名`
- 连接删除时自动清理该连接的所有收藏夹条目
- 连接重命名时自动更新收藏夹中的 `connectionName` 引用
- 表/视图被删除（数据库中不存在）时，收藏夹条目保留但标记为"不可用"（灰色），提示用户手动清理

#### 4.2.2 对象搜索

**搜索命令**：`sql-all-in-one.searchObjects`，快捷键 `Ctrl+Shift+F`

**搜索选项**：

| 选项 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 搜索范围 | 单选 | 当前数据库 | 当前数据库 / 所有数据库 |
| 对象类型 | 多选 | 全选 | 表/视图/函数/存储过程/触发器 |
| 搜索字段 | 多选 | 名称 | 名称/定义/注释 |

**搜索结果**：
- 以扁平列表展示在树视图中
- 每条结果显示：对象类型图标 + 对象名 + 数据库名
- 点击结果 → 定位到树中对应节点或直接打开对象

**ObjectSearchService API**：

| 方法 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `search` | `connectionId, keyword, options` | `Promise<SearchResult[]>` | 搜索数据库对象 |

**SearchResult 结构**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `database` | `string` | 数据库名 |
| `objectType` | `ObjectType` | 对象类型 |
| `objectName` | `string` | 对象名 |
| `matchField` | `string` | 匹配字段（name/definition/comment） |
| `matchContext` | `string` | 匹配上下文（高亮关键字） |

**搜索实现**（按优先级）：
1. **缓存搜索**（优先）：在 `SchemaCache` 已缓存的数据中搜索，速度最快（≤ 50ms）
2. **数据库查询**（回退）：缓存未命中或缓存过期时回退到数据库查询
   - 对象名搜索：使用 `SHOW TABLES LIKE '%keyword%'`
   - 对象定义搜索：查询 `information_schema.ROUTINES` 和 `information_schema.VIEWS`
   - 注释搜索：查询 `information_schema.TABLES` 的 `TABLE_COMMENT`

**搜索限制**：
- 最小搜索长度：≥ 2 个字符
- 输入防抖：300ms
- 搜索结果最多返回 200 条
