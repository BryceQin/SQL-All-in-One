- **文件**: `src/database/commands/QueryCommands.ts`
- **行号**: 210, 215
- **类别**: 安全漏洞
- **影响**: `name` 参数未经任何验证或转义直接拼接到 SQL 语句中，恶意构造的名称可注入任意 SQL

**修复方案**: 对 `name` 进行白名单验证，仅允许字母数字下划线

```typescript
    if (!/^[a-zA-Z_][a-zA-Z0-9_]*$/.test(name)) {
        throw new Error(`Invalid savepoint name: ${name}`);
    }
    return name;
}

if (adapter) await adapter.execute(`SAVEPOINT ${validateSavepointName(name)}`);
if (adapter) await adapter.execute(`ROLLBACK TO SAVEPOINT ${validateSavepointName(name)}`);
```

### 5. 所有 Webview 缺少 CSP（内容安全策略）

- **文件**:
    - `src/views/queryResult/resultPanel.html`
    - `src/views/explainPlan/explainPanel.html`
    - `src/views/tableDesigner/designerPanel.html`
    - `src/views/dataTransfer/transferDialog.html`

- **类别**: 安全隐患
- **影响**: Webview 可加载任意来源的脚本和样式，存在 XSS 攻击面

**修复方案**: 在每个 HTML 文件的 `<head>` 中添加 CSP meta 标签

```html
<meta
    http-equiv="Content-Security-Policy"
    content="default-src 'none'; 
               style-src 'unsafe-inline' {{CSP_SOURCE}}; 
               script-src 'unsafe-inline' {{CSP_SOURCE}}; 
               img-src data: {{CSP_SOURCE}}; 
               font-src {{CSP_SOURCE}};"
/>
```

注意: 由于当前所有 Webview 使用 inline `onclick` 事件处理器，CSP 中 `script-src` 需要包含 `'unsafe-inline'`。后续应逐步迁移到 `addEventListener` 方式以移除 `unsafe-inline`。

```typescript
    this._onDidChangeConnectionState.dispose();
    this._onDidChangeActiveConnection.dispose();
}
```

### 9. disconnectAll() 串行断开连接

- **文件**: `src/database/connection/ConnectionManager.ts`
- **行号**: 193-211
- **类别**: 性能/可靠性
- **影响**: 所有连接串行断开，若某个连接挂起（如网络超时），后续连接无法及时断开

**修复方案**: 使用 `Promise.allSettled()` 并行断开

```typescript
async disconnectAll(): Promise<void> {
    const ids = Array.from(this.adapters.keys());
    const results = await Promise.allSettled(
        ids.map(id => this.disconnect(id))
    );
    for (const result of results) {
        if (result.status === 'rejected') {
            console.error('Failed to disconnect:', result.reason);
        }
    }
}
```

## P2 — 中优先级问题（可计划修复）

### 10. DI 容器单例创建竞态条件

- **文件**: `src/core/diContainer.ts`
- **行号**: 25-29
- **类别**: 架构
- **影响**: 两个调用者几乎同时 `get()` 同一个尚未实例化的单例时，工厂函数可能被调用两次

**修复方案**: 添加 "正在创建中" 的中间状态标记

```typescript
private creating = new Set<string>();

get<T>(token: string): T | undefined {
    if (this.services.has(token)) {
        return this.services.get(token) as T;
    }
    if (this.singletons.has(token) && !this.creating.has(token)) {
        this.creating.add(token);
        try {
            const factory = this.singletons.get(token) as () => T;
            const instance = factory();
            this.services.set(token, instance);
            return instance;
        } finally {
            this.creating.delete(token);
        }
    }
    if (this.factories.has(token)) {
        const factory = this.factories.get(token) as () => T;
        return factory();
    }
    return undefined;
}
```
