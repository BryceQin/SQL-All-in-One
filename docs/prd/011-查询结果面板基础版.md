## 1. 功能概览

实现查询结果的 Webview 展示面板，对标 Navicat 的数据查看器。本迭代为基础版本，支持网格视图、分页、排序、筛选和基础导出。

| 编号 | 功能                  | 一句话描述                             | 用户感知强度 |
| ---- | --------------------- | -------------------------------------- | ------------ |
| P0-1 | 结果面板 Webview 框架 | 虚拟滚动的数据网格 + 三标签切换        | ★★★★★        |
| P0-2 | 分页、排序与筛选      | Navicat 风格的分页、列排序、多条件筛选 | ★★★★☆        |
| P0-3 | 基础数据导出          | CSV / JSON / SQL INSERT / DDL 导出     | ★★★☆☆        |

## 2. P0-1：结果面板 Webview 框架

### 2.1 背景与问题

查询结果需要以美观的表格形式展示，替代 010 迭代中的 OutputChannel 文本输出。对标 Navicat 的数据查看器 Grid View。

### 2.2 功能需求

#### 2.2.1 QueryResultPanel API

| 方法          | 参数                  | 说明         |
| ------------- | --------------------- | ------------ |
| `showResult`  | `result: QueryResult` | 展示查询结果 |
| `showLoading` | `sql: string`         | 显示加载状态 |
| `showError`   | `error: QueryError`   | 显示错误信息 |
| `clear`       | 无                    | 清空面板     |

#### 2.2.2 面板布局

```
┌──────────────────────────────────────────────────────────────┐
│ 📊 查询结果 - 开发库-MySQL 🔴                    耗时: 23ms  │
├──────────────────────────────────────────────────────────────┤
│ 工具栏: [▶ 执行] [⏹ 取消] [🔄 刷新] [📥 导出▼] [🔍 筛选]   │
├──────────┬──────────┬──────────┬─────────────────────────────┤
│ id       │ name     │ email    │ created_at                  │
│ INT 🔑   │ VARCHAR  │ VARCHAR  │ DATETIME                    │
├──────────┼──────────┼──────────┼─────────────────────────────┤
│ 1        │ Alice    │ a@b.com  │ 2024-01-01 00:00            │
│ 2        │ Bob      │ b@b.com  │ 2024-01-02 00:00            │
│ ...      │ ...      │ ...      │ ...                         │
├──────────┴──────────┴──────────┴─────────────────────────────┤
│ [结果集] [消息] [历史]                                        │
├──────────────────────────────────────────────────────────────┤
│ 记录数: 1234  耗时: 0.023s                                    │
└──────────────────────────────────────────────────────────────┘
```

#### 2.2.3 三标签切换

| 标签       | 功能                             | Navicat 对标                 |
| ---------- | -------------------------------- | ---------------------------- |
| **结果集** | 表格展示查询结果                 | Navicat 数据编辑器 Grid View |
| **消息**   | 执行日志、错误信息、影响行数     | Navicat 消息面板             |
| **历史**   | 当前会话查询历史，可点击重新执行 | Navicat 查询历史             |

**说明**："历史"标签页展示当前会话的查询历史（内存中），与 PRD-010 的 `QueryHistory`（持久化存储）共享数据源。标签页中的历史条目点击可重新执行对应 SQL。

#### 2.2.4 数据网格功能

| 功能         | 说明                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 虚拟滚动     | 大数据集（1000+行）只渲染可见行，保证流畅                                                                                    |
| 列头固定     | 滚动时列头固定在顶部                                                                                                         |
| 列宽自适应   | 根据内容自动调整列宽，最小 80px                                                                                              |
| 列头类型图标 | 列名下方显示数据类型（INT 🔑 / VARCHAR / DATETIME）                                                                          |
| NULL 高亮    | NULL 值灰色斜体显示，与空字符串区分                                                                                          |
| NULL 编辑    | 编辑 NULL 单元格时输入框显示为空。清空输入框并提交 → 写入 NULL（非空字符串）。右键菜单提供"设置为 NULL"/"设置为空字符串"选项 |
| 单元格复制   | 选中单元格后 Ctrl+C 复制                                                                                                     |
| 行号         | 左侧显示行号                                                                                                                 |

#### 2.2.4a 大数据量处理策略

对于返回大量数据的查询结果，采用以下优化策略：

| 策略         | 说明                                               |
| ------------ | -------------------------------------------------- |
| 分页加载     | 默认限制 1000 行，提供"加载更多"按钮               |
| 滚动预加载   | 滚动到接近底部时自动加载下一页                     |
| 结果截断提示 | 结果被截断时显示提示："结果已截断，显示前 1000 行" |
| 智能采样     | 超大数据集提供数据采样选项（随机/前N/后N）         |

以上配置使用 PRD-008 中定义的 `sql-all-in-one.query.maxRows`（默认 1000）控制最大显示行数，使用本迭代新增的 `sql-all-in-one.query.pageSize`（默认 100）控制分页加载每页行数。滚动预加载默认启用。

#### 2.2.4b 数据类型智能渲染

根据列数据类型提供智能渲染和交互：

| 数据类型      | 渲染方式                                  |
| ------------- | ----------------------------------------- |
| JSON/JSONB    | 语法高亮 + 折叠展开 + 格式化按钮          |
| XML           | 语法高亮 + 格式化                         |
| DATE/DATETIME | 可切换显示格式（本地/UTC/相对时间）       |
| BLOB/BINARY   | 显示大小 + 预览按钮（文本/十六进制/图片） |
| ENUM/SET      | 下拉选择器编辑                            |
| 超长文本      | 截断显示 + 展开按钮                       |
| 布尔值        | 复选框显示                                |
| 地理数据      | （可选）地图可视化                        |

以上渲染选项通过 `sql-all-in-one.results.*` 配置项控制，详见 §5 配置项汇总。

#### 2.2.4c 结果集比较

支持比较两个查询结果集的差异：

| 功能       | 说明                          |
| ---------- | ----------------------------- |
| 行级别比较 | 高亮新增、删除、修改的行      |
| 列级别比较 | 高亮值有变化的单元格          |
| 主键匹配   | 基于主键列进行行匹配          |
| 差异导出   | 导出差异报告（JSON/HTML/CSV） |

**操作流程**：

1. 执行第一个查询，结果显示在结果面板
2. 点击"比较"按钮，选择比较来源（历史记录/文件/新查询）
3. 加载第二个结果集
4. 显示差异对比视图，左侧为基准，右侧为比较
5. 提供"导出差异"按钮

#### 2.2.5 工具栏

| 按钮     | 功能                                      |
| -------- | ----------------------------------------- |
| ▶ 执行   | 重新执行当前 SQL                          |
| ⏹ 取消   | 取消正在执行的查询                        |
| 🔄 刷新  | 刷新查询结果                              |
| 📥 导出▼ | 导出下拉菜单（CSV/JSON/INSERT/DDL/Excel） |
| 🔍 筛选  | 展开/收起筛选栏                           |
| 🆚 比较  | 打开结果集比较功能                        |

#### 2.2.6 面板标题

格式：`📊 查询结果 - {连接名} {连接颜色圆点} 耗时: {ms}ms`

#### 2.2.7 Webview 通信协议

**扩展 → Webview**：

| 消息类型      | 数据          | 说明     |
| ------------- | ------------- | -------- |
| `queryResult` | `QueryResult` | 查询结果 |

**Webview → 扩展**：

| 消息类型        | 数据                    | 说明     |

| `requestSort`   | `{ column, direction }` | 请求排序 |

| `requestPage`   | `{ page }`              | 请求分页 |

#### 2.2.8 集成到 SQL 执行流程

修改 010 迭代的执行命令处理器：

- 查询开始 → `QueryResultPanel.showLoading()`

- 查询失败 → `QueryResultPanel.showError()`

## 3. P0-2：分页、排序与筛选

### 3.1 背景与问题

大数据集需要分页浏览，用户需要按列排序和筛选数据。对标 Navicat 的排序和筛选功能。

### 3.2 功能需求

#### 3.2.1 分页

| 项目         | 规格                            |
| ------------ | ------------------------------- |
| 默认每页行数 | 100                             |
| 分页控件     | 上一页 / 下一页 / 页码跳转      |
| 状态显示     | "显示 1-100 / 共 1,234 行"      |
| 可配置       | `sql-all-in-one.query.pageSize` |

分页切换时发送 `requestPage` 消息到扩展端，扩展端重新查询对应范围的数据（使用 `LIMIT offset, count`）。

> **性能注意**：大偏移量分页（如第 50 页，`LIMIT 4900, 100`）在 MySQL 中性能较差。第一版使用 `LIMIT offset, count` 方案，后续迭代考虑升级为键集分页（Keyset Pagination，基于上一页最后一条记录的主键值）。

#### 3.2.2 列排序

| 操作     | 行为                               |
| -------- | ---------------------------------- |
| 点击列头 | 升序 → 降序 → 取消排序（三态循环） |
| 排序图标 | ▲ 升序 / ▼ 降序 / 无图标           |
| 多列排序 | 暂不支持，仅支持单列排序           |

排序策略：

- 客户端排序：对已加载的数据直接排序（小数据集，≤ 1000 行）
- 服务端排序：重新查询 `SELECT ... ORDER BY column ASC/DESC`（大数据集）
- 单列排序，暂不支持多列排序

#### 3.2.3 筛选栏

Navicat 风格多条件筛选：

```
┌──────────────────────────────────────────────────────────────┐
│ 筛选: [列名 ▼] [运算符 ▼] [值________] [＋添加条件] [应用]   │
│       status     =        'active'                            │
│       age        >        18                                  │
└──────────────────────────────────────────────────────────────┘
```

**运算符选项**：

| 运算符        | 说明       |
| ------------- | ---------- |
| `=`           | 等于       |
| `!=`          | 不等于     |
| `>`           | 大于       |
| `<`           | 小于       |
| `>=`          | 大于等于   |
| `<=`          | 小于等于   |
| `LIKE`        | 模糊匹配   |
| `NOT LIKE`    | 不匹配     |
| `IN`          | 在列表中   |
| `NOT IN`      | 不在列表中 |
| `IS NULL`     | 为空       |
| `IS NOT NULL` | 不为空     |
| `BETWEEN`     | 在范围内   |

**筛选行为**：

- 点击"应用"按钮 → 生成 WHERE 子句 → 重新查询
- 点击"＋添加条件" → 添加新的筛选行
- 每行右侧有删除按钮
- 多条件之间为 AND 关系

**安全约束**（防止 SQL 注入）：

- 列名必须从 `ColumnMeta[]` 白名单中校验，不允许自由输入
- 运算符必须从预定义集合中选择，不允许自由输入
- 值使用参数化查询（`?` 占位符），禁止字符串拼接
- 扩展端生成 WHERE 子句时，对标识符使用反引号包裹（MySQL）以处理特殊字符

#### 3.2.4 FilterCondition 结构

| 字段       | 类型     | 说明   |
| ---------- | -------- | ------ |
| `column`   | `string` | 列名   |
| `operator` | `string` | 运算符 |
| `value`    | `string` | 值     |

### 3.3 验收标准

- [ ] 分页控件正确显示和切换
- [ ] 点击列头切换排序状态
- [ ] 排序图标正确显示
- [ ] 筛选栏可添加/删除条件

## 4. P0-3：基础数据导出

### 4.1 背景与问题

用户需要将查询结果或表数据导出为多种格式。对标 Navicat 的导出向导。

### 4.2 功能需求

#### 4.2.1 DataExporter API

| 方法             | 参数                       | 返回值          | 说明               |
| ---------------- | -------------------------- | --------------- | ------------------ |
| `exportToCsv`    | `rows, columns, options`   | `Promise<void>` | 导出 CSV           |
| `exportToJson`   | `rows, columns, options`   | `Promise<void>` | 导出 JSON          |
| `exportToInsert` | `rows, columns, tableName` | `Promise<void>` | 导出 SQL INSERT    |
| `exportToDdl`    | `adapter, database, table` | `Promise<void>` | 导出 DDL           |
| `exportToExcel`  | `rows, columns, options`   | `Promise<void>` | 导出 Excel (.xlsx) |

**优先级说明**：Excel 导出（`exportToExcel`）标记为 **P1**，需要引入 `exceljs` 或 `xlsx` 库。第一版仅实现 CSV/JSON/SQL INSERT/DDL 四种格式。

#### 4.2.2 导出格式

| 格式       | 说明                                         | 配置选项                           |
| ---------- | -------------------------------------------- | ---------------------------------- |
| CSV        | 带表头，可配置分隔符/编码                    | 分隔符、编码、是否包含表头         |
| JSON       | 数组格式 `[{}, {}]`                          | 格式化/压缩                        |
| SQL INSERT | `INSERT INTO table (cols) VALUES (vals);`    | 批量大小（每条 INSERT 包含的行数） |
| DDL        | `CREATE TABLE ...`                           | —                                  |
| Excel      | .xlsx 格式，支持样式（表头加粗、列宽自适应） | 表名作为工作表名                   |

#### 4.2.3 导出流程

1. 用户点击"导出▼"下拉选择格式
2. 弹出保存文件对话框（`vscode.window.showSaveDialog`）
3. 生成导出内容
4. 写入文件
5. 状态栏显示"导出成功"临时消息

#### 4.2.4 CSV 导出规格

| 项目      | 默认值                                       |
| --------- | -------------------------------------------- |
| 分隔符    | `,`                                          |
| 编码      | `utf-8`                                      |
| 包含表头  | 是                                           |
| 引号      | 双引号，仅对包含分隔符/换行/引号的字段加引号 |
| NULL 表示 | 空字符串                                     |

#### 4.2.5 JSON 导出规格

```json
[
    { "id": 1, "name": "Alice", "email": "a@b.com" },
    { "id": 2, "name": "Bob", "email": "b@b.com" }
]
```

- NULL 值表示为 `null`
- 日期时间表示为 ISO 8601 字符串
- Buffer/BLOB 表示为 base64 字符串

#### 4.2.6 SQL INSERT 导出规格

```sql
INSERT INTO users (id, name, email) VALUES (1, 'Alice', 'a@b.com');
INSERT INTO users (id, name, email) VALUES (2, 'Bob', 'b@b.com');
```

- 字符串值用单引号包裹
- NULL 表示为 `NULL`
- 数值不包裹
- 默认每条 INSERT 一行（可配置批量）
