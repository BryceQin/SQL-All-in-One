# PRD-004: 中英双语国际化

**版本**: V1.0  
**创建日期**: 2026-05-20  
**状态**: Draft

---

## 1. 概述

当前 SQL All in One 插件约 **230 条用户可见文本**散布在 15-18 个源文件中，处于中英混合状态（约 50% 中文、50% 英文）。本文档定义插件的中英双语国际化方案，通过配置项控制显示语言，覆盖所有用户可见文本表面。

---

## 2. 设计原则

### 2.1 语言切换策略

新增配置项 `SQL-All-in-One.displayLanguage`：

| 值 | 行为 |
|----|------|
| `auto`（默认） | 自动跟随 VSCode 显示语言（`zh-cn` → 中文，其他 → 英文） |
| `zh` | 强制中文 |
| `en` | 强制英文 |

语言切换在插件激活时生效。切换语言后需重新加载窗口方可全部生效（package.json 的 nls 在构建时注入，运行时不可变）。

### 2.2 i18n 架构选型

采用 VS Code 标准 i18n 机制：

| 层面 | 方案 | 说明 |
|------|------|------|
| package.json 描述 | `package.nls.json` + `package.nls.zh-cn.json` | VS Code 原生 NLS 支持，`%key%` 占位符 |
| 运行时消息 | `src/i18n/messages.en.json` + `messages.zh.json` | 轻量 `t()` 函数，动态加载 |
| 静态文档 | `README.md` + `README.en.md` 双文件 | VS Code 集市原生支持多语言 README |

## 4. i18n 核心模块设计

### 4.1 `src/i18n/index.ts`

```typescript
import * as vscode from 'vscode';

type Language = 'zh' | 'en';
type MessageKey = string;

let currentLang: Language = 'zh';
let messages: Record<MessageKey, string> = {};

export function initI18n(): void {
    const config = vscode.workspace.getConfiguration('SQL-All-in-One');
    const userLang = config.get<string>('displayLanguage', 'auto');

    if (userLang === 'auto') {
        currentLang = vscode.env.language === 'zh-cn' ? 'zh' : 'en';
    } else {
        currentLang = userLang as Language;
    }

    messages = require(`./messages.${currentLang}.json`);
}

/** Get translated text with optional {0}, {1} placeholder substitution */
export function t(key: MessageKey, ...args: string[]): string {
    let template = messages[key];
    if (template === undefined) {
        console.warn(`[i18n] Missing translation key: ${key}`);
        return key;
    }
    args.forEach((arg, i) => {
        template = template.replace(`{${i}}`, arg);
    });
    return template;
}

/** Get current language */
export function getLanguage(): Language {
    return currentLang;
}
```

### 4.2 使用示例

```typescript
// 之前：硬编码
showWarningMessage('No active editor found');

// 之后：通过 t() 获取翻译
import { t } from '../i18n';
showWarningMessage(t('notification.noActiveEditor'));

// 带占位符
t('diagnostic.missingColumnAfterComma', String(lineNum));
```

## 9. 非功能需求

### 9.1 性能

- `initI18n()` 在插件激活时调用一次，`require()` JSON 文件后缓存在内存
- `t()` 函数为 O(n) 字符串替换（n = args 数量，通常 0-3），零性能影响
- 翻译 JSON 文件大小约 15-20 KB（130+ 条消息），加载可忽略

### 9.2 可维护性

- 新增文本只需在 `messages.en.json` 和 `messages.zh.json` 中同步添加对应 key
- Key 命名有规律（`类别.场景`），易于查找
- 翻译缺失时 `t()` 打印 warn 并返回 key 本身，不会因漏添加翻译而崩溃
