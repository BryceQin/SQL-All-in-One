Navicat 的表设计器是可视化数据库设计的重要工具，允许用户通过图形界面设计表结构，自动生成 DDL。

#### 2.2.3 六标签页

**字段标签页**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 字段名 | 文本输入 | 是 | 列名 |
| 类型 | 下拉选择 | 是 | MySQL 数据类型（INT, VARCHAR, TEXT, DATETIME 等） |
| 长度 | 数字输入 | 条件必填 | 类型长度/精度 |
| 允空 | 复选框 | — | 是否允许 NULL |
| 默认值 | 文本输入 | 否 | 默认值（特殊值：AUTO_INCREMENT、CURRENT_TIMESTAMP） |
| 备注 | 文本输入 | 否 | 列注释 |
| 约束 | 按钮组 | — | PK / UNIQUE / AI 快捷设置 |

**类型下拉**：按分类组织

> **方言适配说明**：以下为 MySQL 的数据类型列表。数据类型通过 `IDatabaseAdapter.getSupportedDataTypes()` 动态获取（PRD-008 新增接口）。不同方言返回各自的类型列表，表设计器根据连接方言渲染对应的类型下拉。
> 
> 第一版仅实现 MySQL 类型，其他方言在适配器实现时提供对应数据。

| 分类 | 类型 |
|------|------|
| 整数 | TINYINT, SMALLINT, MEDIUMINT, INT, BIGINT |
| 浮点 | FLOAT, DOUBLE, DECIMAL |
| 字符串 | CHAR, VARCHAR, TINYTEXT, TEXT, MEDIUMTEXT, LONGTEXT |
| 二进制 | BINARY, VARBINARY, TINYBLOB, BLOB, MEDIUMBLOB, LONGBLOB |
| 日期 | DATE, TIME, DATETIME, TIMESTAMP, YEAR |
| 其他 | ENUM, SET, JSON, BOOLEAN, BIT |

**SQL 预览标签页**：

- 实时显示当前设计对应的 DDL
- 新建表 → `CREATE TABLE ...`
- 编辑表 → `ALTER TABLE ...`
- 语法高亮显示

#### 2.2.4 字段拖拽排序

- 字段行支持拖拽调整顺序
- 拖拽时显示插入位置指示线
- 拖拽后 SQL 预览实时更新
- 编辑已有表时，拖拽排序可能导致 `ALTER TABLE ... MODIFY COLUMN ... AFTER ...` 重建表（InnoDB 大表极慢）
- 拖拽排序完成时弹出提示："列顺序变更将重建表，大表可能耗时较长。建议导出 SQL 后手动执行"
- 提供"仅导出 SQL"选项（将 DDL 写入 .sql 文件而非直接执行）

#### 2.2.5 保存流程

```
1. 用户点击"保存"
1a. 保存前校验：
   - 字段名不能为空、不能与已有字段重名
   - 索引名不能为空、不能与已有索引重名
   - 外键名不能为空、不能与已有外键重名
   - 至少需要一个字段（表不能为空）
   - 校验失败时在对应行显示红色错误提示，阻止保存
2. 生成 DDL SQL
3. 弹出确认对话框，显示即将执行的 SQL
4. 用户确认后：
   a. 调用 adapter.execute(sql)
   b. 成功 → 调用 `SchemaCache.invalidate(connectionId, 'table')` 刷新 Schema 缓存（PRD-013），关闭设计器
   c. 失败 → 显示错误，保留设计器
5. 用户取消 → 不执行
```

#### 2.2.6 编辑已有表

- 打开时调用 `adapter.describeTable()` 加载当前结构
- 修改字段 → 生成 `ALTER TABLE ... MODIFY COLUMN ...`
- 新增字段 → 生成 `ALTER TABLE ... ADD COLUMN ...`
- 删除字段 → 生成 `ALTER TABLE ... DROP COLUMN ...`
- 重命名字段 → 生成 `ALTER TABLE ... CHANGE COLUMN ...`

#### 2.2.7 Webview 通信协议

**扩展 → Webview**：

| 消息类型 | 数据 | 说明 |
|---------|------|------|
| `tableStructure` | `TableStructure` | 表结构数据 |
| `saveResult` | `{ success, error? }` | 保存结果 |

**Webview → 扩展**：

| 消息类型 | 数据 | 说明 |
|---------|------|------|
| `save` | `TableDesign` | 保存设计 |
| `requestTableList` | — | 请求表列表（外键引用） |
| `requestColumnList` | `{ table }` | 请求列列表 |

## 4. 验收标准

### 4.1 功能验收

| 编号 | 验收项 | 验证方式 |
|------|--------|---------|
| AC-01 | 新建表 | 设计字段 → 保存 → 表创建成功 |
| AC-02 | 编辑表 | 修改字段 → 保存 → ALTER TABLE 执行成功 |
| AC-03 | 添加字段 | 新增行 → 保存 → ADD COLUMN 执行成功 |
| AC-04 | 删除字段 | 删除行 → 保存 → DROP COLUMN 执行成功 |
| AC-05 | 添加索引 | 新增索引 → 保存 → CREATE INDEX 执行成功 |
| AC-06 | 添加外键 | 新增外键 → 保存 → ALTER TABLE ADD FK 成功 |
| AC-07 | SQL 预览 | 修改设计 → SQL 预览实时更新 |
| AC-08 | 保存确认 | 点击保存 → 弹出确认 → 显示 SQL |
