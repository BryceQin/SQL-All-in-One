# PRD-003: 格式化配置增强

**版本**: V1.0  
**创建日期**: 2026-05-20  
**状态**: Draft

---

## 1. 概述

当前 SQL All in One 插件提供 **39 个** FormatOptions 配置项，覆盖了基础的大小写、换行、缩进、对齐、逗号、分号等主流维度。但经过系统性分析，仍存在以下缺口：

- **子句换行控制不对称**：大量子句只有"之前"或"之后"的换行控制，缺少对称项（如 `newlineBeforeGroupBy` 有但无 `newlineAfterGroupBy`）
- **高频 SQL 结构缺少专项控制**：CTE（WITH 子句）、INSERT 语句、CASE 表达式、窗口函数、IN 列表等没有细粒度格式化选项
- **大小写选项不完整**：缺少 NULL、TRUE/FALSE 等关键字的独立大小写控制
- **方言特有语法无法控制**：Hive 的 LATERAL VIEW / DISTRIBUTE BY / CLUSTER BY / SORT BY，Oracle 的 CONNECT BY / START WITH

本文档定义 **43 个新增格式化配置项**，一次交付。

---

## 2. 设计原则

### 2.1 严格向后兼容

所有新增选项使用可选字段（`?`），默认值等于当前硬编码行为。用户不显式修改设置的情况下，格式化结果与升级前完全一致。

### 2.2 方言通用暴露

方言特有选项（Hive 4 项 + Oracle 2 项）对所有方言的 VSCode 设置面板可见，仅在非适用方言下不生效。不通过 `when` 条件过滤，降低维护复杂度。

### 2.3 VSCode 设置分组

82 个配置项（39 现有 + 43 新增）按功能域分为 8 个设置分组，通过 `package.json` 的 `order` 字段归类：

| 分组 | 现有项 | 新增项 | 合计 |
|------|--------|--------|------|
| Dialect & Indent | 5 | 0 | 5 |
| Case Options | 6 | 2 | 8 |
| Newline Control | 14 | 18 | 32 |
| Comma & Operators | 4 | 0 | 4 |
| Alignment | 4 | 4 | 8 |
| Clause Formatting | 0 | 13 | 13 |
| Whitespace & Misc | 6 | 4 | 10 |
| Dialect Specific | 0 | 6 | 6 |
| **合计** | **39** | **43** | **82** |

## 3. 新增配置项规格

### 3.1 新增类型别名

```typescript
type CteCommaPosition = 'before' | 'after'
type SubqueryParenStyle = 'inline' | 'newline'
type CommentPosition = 'preserve' | 'newline' | 'inline'
```

所有新增字段均为可选（`?`），追加到 `FormatOptions` 接口中。

---

### 3.2 分组 2: Case Options（2 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `nullCase` | `preserve \| upper \| lower` | `preserve` | NULL 关键字独立大小写控制 |
| `booleanCase` | `preserve \| upper \| lower` | `preserve` | TRUE / FALSE 关键字独立大小写控制 |

**生效范围**: 所有方言。  
**优先级**: 当用户同时设置 `keywordCase` 和 `nullCase`/`booleanCase` 时，后两者优先。  
**实现**: 在 `ExpressionFormatter` 中为 NULL、TRUE、FALSE Token 单设格式化路径，优先读取 `nullCase`/`booleanCase`，fallback 到 `keywordCase`。

### 3.3 分组 3: Newline Control（18 项）

#### 3.3.1 子句换行补全（9 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `newlineAfterGroupBy` | `boolean` | `true` | GROUP BY 后字段列表是否换行 |
| `newlineAfterHaving` | `boolean` | `true` | HAVING 后条件表达式是否换行 |
| `newlineAfterOrderBy` | `boolean` | `true` | ORDER BY 后排序列是否换行 |
| `newlineAfterLimit` | `boolean` | `false` | LIMIT 后数字是否换行 |
| `newlineAfterJoin` | `boolean` | `true` | JOIN 后表名/子查询是否换行 |
| `newlineBeforeSetOperation` | `boolean` | `true` | UNION / INTERSECT / EXCEPT 前是否换行 |
| `newlineAfterSetOperation` | `boolean` | `true` | 集合操作关键字后是否换行 |
| `newlineBeforeOn` | `boolean` | `true` | JOIN ... ON 的 ON 关键字是否换行 |
| `newlineBeforeUsing` | `boolean` | `true` | JOIN ... USING 的 USING 关键字是否换行 |

**行为对比示例**:

```sql
-- newlineAfterGroupBy: false           -- newlineAfterGroupBy: true
SELECT a, COUNT(*)                      SELECT a, COUNT(*)
FROM t                                  FROM t
GROUP BY a                              GROUP BY
                                        a

-- newlineAfterLimit: false (default)   -- newlineAfterLimit: true
SELECT * FROM t                         SELECT * FROM t
LIMIT 10                                LIMIT
                                        10

-- newlineBeforeOn: true (default)      -- newlineBeforeOn: false
SELECT *                                SELECT *
FROM a                                  FROM a
JOIN b                                  JOIN b ON a.id = b.id
ON a.id = b.id

-- newlineBeforeSetOperation: true      -- newlineBeforeSetOperation: false
SELECT * FROM a                         SELECT * FROM a UNION ALL
UNION ALL                               SELECT * FROM b
SELECT * FROM b
```

#### 3.3.2 CTE / WITH 子句（5 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `newlineBeforeWith` | `boolean` | `true` | WITH 关键字前是否换行 |
| `newlineAfterWith` | `boolean` | `true` | WITH 关键字后（第一个 CTE 名前）是否换行 |
| `indentCteBody` | `boolean` | `true` | CTE 子查询体是否相对于 AS ( 缩进一级 |
| `newlineBetweenCtes` | `boolean` | `true` | 多个 CTE 之间是否插入独立空行分隔 |
| `cteCommaPosition` | `before \| after` | `before` | CTE 定义之间的逗号位于行首还是行尾 |

**行为对比示例**:

```sql
-- indentCteBody: true (default)        -- indentCteBody: false
WITH cte AS (                           WITH cte AS (
    SELECT * FROM t1                    SELECT * FROM t1
)                                       )
SELECT * FROM cte                       SELECT * FROM cte

-- cteCommaPosition: 'before' (default) -- cteCommaPosition: 'after'
WITH                                    WITH
  a AS (SELECT 1)                         a AS (SELECT 1),
  , b AS (SELECT 2)                       b AS (SELECT 2)
SELECT * FROM a                         SELECT * FROM a

-- newlineBetweenCtes: false            -- newlineBetweenCtes: true (default)
WITH                                    WITH
  a AS (SELECT 1),                        a AS (SELECT 1),
  b AS (SELECT 2)                                               <-- 空行
SELECT * FROM a                           b AS (SELECT 2)
                                        SELECT * FROM a
```

### 3.4 分组 4: Alignment（4 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `indentJoinConditions` | `boolean` | `true` | JOIN ON 后的条件是否相对于 JOIN 缩进一级 |
| `alignOnClauses` | `boolean` | `false` | ON 条件中多个 AND/OR 条件关键字是否对齐 |
| `alignInsertColumns` | `boolean` | `false` | INSERT 列名列表与 VALUES 值列表是否列对齐 |
| `alignInsertValuesGroups` | `boolean` | `false` | 多行 VALUES 组之间的值是否对齐 |

**行为对比示例**:

```sql
-- indentJoinConditions: true (default) -- indentJoinConditions: false

FROM a                                  FROM a
JOIN b                                  JOIN b
  ON a.id = b.id                        ON a.id = b.id
  AND a.type = 'X'                      AND a.type = 'X'

-- alignOnClauses: false (default)      -- alignOnClauses: true
JOIN b                                  JOIN b
  ON a.id = b.id                          ON a.id = b.id
  AND a.type = 'X'                       AND a.type = 'X'
  OR a.status = 1                        OR a.status = 1

-- alignInsertColumns: false (default)  -- alignInsertColumns: true
INSERT INTO t (col1, col2)              INSERT INTO t (col1, col2)
VALUES (1, 2)                           VALUES           (1, 2)

-- alignInsertValuesGroups: false       -- alignInsertValuesGroups: true
INSERT INTO t (a, b)                    INSERT INTO t (a, b)
VALUES                                  VALUES
  (1, 'x'),                               (1, 'x'),
  (2, 'yy')                               (2, 'yy')
```

#### 3.5.2 CASE 表达式（6 项）

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `newlineAfterCase` | `boolean` | `true` | CASE 关键字后是否换行 |
| `newlineAfterWhen` | `boolean` | `true` | WHEN 条件表达式后是否换行 |
| `newlineAfterThen` | `boolean` | `false` | THEN 后的结果表达式是否换行 |
| `newlineAfterElse` | `boolean` | `false` | ELSE 后的结果表达式是否换行 |
| `indentWhen` | `boolean` | `true` | WHEN 关键字是否相对于 CASE 缩进一级 |
| `indentThen` | `boolean` | `true` | THEN 关键字是否相对于 WHEN 缩进一级 |

**行为对比示例**:

```sql
-- indentWhen: true, indentThen: true   -- indentWhen: false, indentThen: false
CASE                                    CASE
  WHEN x > 0 THEN                        WHEN x > 0 THEN
    'positive'                           'positive'
  WHEN x < 0 THEN                        WHEN x < 0 THEN
    'negative'                           'negative'
  ELSE                                   ELSE
    'zero'                               'zero'
END                                     END

-- newlineAfterThen: false (default)    -- newlineAfterThen: true
CASE                                    CASE
  WHEN x > 0 THEN 'positive'              WHEN x > 0 THEN
  ELSE 'zero'                               'positive'
END                                       ELSE
                                            'zero'
                                        END
```

## 8. 非功能需求

### 8.1 性能

- 新增选项均为简单布尔/枚举判断，不应引入额外循环或复杂计算
- `maxItemsInlineList` 的 IN 列表计数为 O(n) 遍历，对大型 SQL 影响可忽略
- `commentPosition` 的注释提取为现有分词流上的标记过滤，无额外解析开销

### 8.2 可维护性

- 所有新增选项集中在 `FormatOptions` 接口定义，与现有选项管理方式一致
- `defaultOptions` 对象按相同分组注释，便于查找对比
- 方言特有选项在 `ExpressionFormatter` 中通过 `dialect.name` 判断是否生效
