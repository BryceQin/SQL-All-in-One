全面 UI/UX 优化方案

现代玻璃拟态风格 — 架构 + 视觉 + 交互

一、架构层面优化

❌ 当前问题
  • 查询结果同时输出到 OutputChannel + Webview，但 Webview 可能未正确显示
  • OutputChannel 纯文本无格式，对齐混乱
  • 用户看到的是控制台黑底白字，体验差
  • 两套面板（QueryResult + TableDesigner）样式不统一
✅ 优化目标
  • Webview 面板作为主要展示，确保正确渲染
  • OutputChannel 降级为辅助日志，仅记录执行信息
  • 统一两套面板的设计语言和 CSS 变量体系
  • 玻璃拟态风格，深色/浅色主题自动适配

三、交互优化

🔘 按钮系统
• 主操作：渐变背景 + 投影发光
• 次要操作：半透明 + 微妙边框
• hover：背景变亮 + 微妙上移
• active：缩放0.96 + 投影收缩
📝 输入框
• 默认：透明边框，融入背景
• hover：显示边框 + 背景浮现
• focus：蓝色边框 + 发光环
• error：红色边框 + 抖动动画
📊 数据网格
• 行hover：微妙高亮过渡
• 选中行：accent色半透明背景
• 编辑单元格：蓝色轮廓 + 内嵌input
• 排序列：表头显示方向箭头

四、实施范围

1
修复 Webview 面板显示
确保 QueryResultPanel 在 viewTableData 时正确渲染和聚焦，OutputChannel 降级为辅助日志
2
统一 CSS 变量体系
合并两套面板的 CSS 变量，建立玻璃拟态设计系统
3
Query Result 面板美化
毛玻璃容器、智能数据标签、精致工具栏、微交互动画
4
Table Designer 面板美化
类型彩色标签、约束按钮优化、Save按钮渐变发光、SQL预览美化
5
OutputChannel 输出优化
保留执行日志但不再输出表格数据，改为提示"查看 Query Result 面板"
